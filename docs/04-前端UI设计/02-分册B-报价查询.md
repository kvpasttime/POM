## 4. 页面详细设计

### 4.1 [PAGE-002] 报价搜索结果页

#### 4.1.1 页面元信息

- 页面 ID: PAGE-002
- 页面类型: 列表页（搜索+筛选+结果一体）
- 关联功能: F-014/F-015/F-016/F-019/F-021（删除入口）
- 关联业务规则: R-QRY-01~06、R-QRY-10、R-MNT-03；验收 A-QRY-01~03/06
- 路由/入口: /search（登录后默认页）
- 目标角色: 全部

#### 4.1.2 页面目标与入口

- 页面目标: 快速检索历史报价并进入详情
- 上游入口: 登录后落地；顶部菜单"报价搜索"；详情页返回
- 下游去向: 行点击 → PAGE-003
- 返回路径: N/A（顶级页面）
- 前置条件: 有效会话

#### 4.1.4 结构树与布局约束

- 页面根容器
  - 页头区（面包屑）
  - 搜索区（关键词+搜索/重置按钮）
  - 筛选区（两行筛选控件 + 已生效筛选 chips，chip 可单个移除）
  - 结果区（el-table，斑马纹，行悬浮高亮）
  - 分页区（右对齐）
- 布局约束:
  - 表格列横向可滚动（移动端）；优先列：物料名称/供应商/金额/报价日期
  - 筛选条件变化即重查（防抖 300ms）；关键词必须点搜索或回车
  - 状态列用 el-tag：自动识别=info、已确认=success、待核对=warning、无有效报价=info 淡化

#### 4.1.5 字段与组件规格

| 区域 | 字段/组件 | 类型 | 数据来源/去向 | 默认值/格式 | 校验/约束 | 备注 |

#### 4.1.6 操作与状态约束

- 主操作: 搜索/筛选查询
  - 前置条件: 有效会话
  - 成功反馈: 表格刷新；URL query 同步（可分享/刷新保留）
  - 失败反馈: ElMessage.error；表格保持
- 次操作: 重置（清空全部条件并重查）；清除单个筛选 chip
- 页面状态:
  - 初始态: 无条件 → 显示最近导入的报价（默认排序）
  - 加载态: 表格 loading
  - 空态: 按 R-QRY-10（见上图空态示例），不伪造近似结果
  - 错误态: 表格上方 el-alert
  - 无权限态: N/A（全角色可访问）
  - 移动端: 筛选区折叠为"筛选"按钮+抽屉；表格横滚

### 4.2 [PAGE-003] 报价详情页

#### 4.2.1 页面元信息

- 页面 ID: PAGE-003
- 页面类型: 详情页
- 关联功能: F-017/F-018/F-012/F-025/F-020（编辑入口）/F-021（删除入口）/F-022
- 关联业务规则: R-QRY-06~09、R-IMP-25/26、R-SYS-06/07、R-MNT-01~05；验收 A-QRY-04/05、A-MNT-02、A-SYS-04
- 路由/入口: /quotes/:id
- 目标角色: 全部（操作按钮按角色显隐）

#### 4.2.2 页面目标与入口

- 页面目标: 查看单条报价全部结构化信息、原始文本与来源定位
- 上游入口: PAGE-002 行点击；同物料历史列表
- 下游去向: 编辑页（maintainer+）；同物料历史（列表过滤）
- 返回路径: 浏览器返回 / 去搜索页（保留筛选）
- 前置条件: 记录存在且未删除（deleted 仅 admin 可见）

#### 4.2.6 操作与状态约束

- 主操作: 查看各 Tab 内容
  - 前置条件: 记录存在
  - 成功反馈: 内容渲染
  - 失败反馈: 404 → "记录不存在或已删除"
- 次操作: 编辑（→PAGE-008）；删除（二次确认，成功后返回搜索页）；恢复（admin 且记录 deleted 时显示）
- 页面状态:
  - 加载态: 骨架屏
  - 空态: 404 提示
  - 无权限态: deleted 且非 admin → 404 同文案（不泄露存在性）
  - 下载中: 按钮 loading；下载行为后端审计（R-SYS-08）
