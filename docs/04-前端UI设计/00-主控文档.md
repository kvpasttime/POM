## 文档控制

### 2.2 导航与路由规则

- 路由表:

| 路由 | 页面 | 菜单 | 角色 |
|------|------|------|------|
| /login | PAGE-001 | 无（独立壳） | 公开 |
| /search | PAGE-002 | 报价搜索（默认首页） | 全部 |
| /quotes/:id | PAGE-003 | 无（详情，从搜索/历史进入） | 全部 |
| /quotes/:id/edit | PAGE-008 | 无（从详情进入） | maintainer+ |
| /import | PAGE-004 | 数据导入 | maintainer+ |
| /import/:batchId/map | PAGE-005 | 无（向导第 2 步） | maintainer+ |
| /import/:batchId/report | PAGE-006 | 无（向导第 3 步） | maintainer+ |
| /batches | PAGE-007 | 导入批次 | maintainer+ |
| /users | PAGE-009 | 用户管理 | admin |
| /audit | PAGE-010 | 审计日志 | admin |
| /backup | PAGE-011 | 备份状态 | admin |
| * | 404 页 | — | — |

- 规则:
  - R-UI-01 未登录访问任意业务路由 → 重定向 /login 并携带回跳地址
  - R-UI-02 会话失效 401 → 统一拦截跳 /login，提示"登录已过期"
  - R-UI-03 角色不符访问 → 403 页（不属于任何菜单，显示返回首页）
  - R-UI-04 默认登录后落地 /search

### 2.3 权限显隐规则（引用 03 文档 5.1 矩阵）

| 菜单/入口 | user | maintainer | admin |
|-----------|------|------------|-------|
| 报价搜索/详情 | ✓ | ✓ | ✓ |
| 详情内"编辑/删除/标记"按钮 | 隐藏 | ✓ | ✓ |
| 数据导入/导入批次 | 隐藏 | ✓ | ✓ |
| 记录编辑页路由 | 403 | ✓ | ✓ |
| 用户管理/审计日志/备份状态 | 隐藏 | 隐藏 | ✓ |
| 敏感字段明文 | 脱敏 | 明文 | 明文（R-SYS-07） |

### 2.4 全局交互与状态反馈规范

- 加载态: 表格/卡片区域骨架屏或 v-loading；按钮提交中 loading 且禁用
- 成功反馈: ElMessage.success；失败: ElMessage.error（后端 message 优先）
- 危险操作（删除/停用/覆盖映射）: ElMessageBox 二次确认，红色确认按钮
- 表单校验: 前端初校验 + 后端终校验；后端 422 字段错误回显到对应控件
- 列表空态: 按 R-QRY-10 显示生效筛选与"清除筛选"按钮；无筛选时显示引导文案
- 时间显示: 统一 `YYYY-MM-DD HH:mm`；金额: 千分位+2 位小数；空值显示 `—`
- 脱敏显示: 手机号 `139****4455`；地址/账户 `已脱敏`（user 角色）
- 分页: 默认 20/页，可选 [20,50,100]；总条数展示
- 认证接口响应禁缓存: 前端不缓存业务 GET（Nginx 层同时 no-store）
