## 2. 物理设计基线

### 2.1 存储边界

- 数据库：`pom`
- 写入方：POM FastAPI 后端（单体，唯一写入方）
- 读取方：POM 后端（前端不直连）
- Schema：public（SQLite 开发环境无 schema 概念，默认主库）

### 2.2 数据库兼容与类型口径

| 项目 | 设计口径 |
| --- | --- |
| 主兼容目标 | PostgreSQL 15+（生产） |
| 兼容要求 | 本地开发使用 SQLite 10+（ADR-005），禁止使用 PG 专有类型与语法 |
| 主键类型 | `bigint` 自增（SQLite 为 INTEGER 自增） |
| 字符串类型 | `varchar(n)`；超长文本使用 `text` |
| 时间类型 | 文中统一写 `datetime(3)`；PG 落地为 `timestamp(3)`；SQLite 为 TEXT ISO8601 |
| JSON 类型 | 文中统一写 `json`；PG 落地 `json`；SQLite 落地 TEXT（应用层序列化） |
| 布尔类型 | `boolean`（SQLite 0/1） |
| 枚举落地 | 统一按 `varchar` + 应用枚举校验实现，不依赖数据库原生 enum |
| 大小写不敏感查询 | 应用层统一 `lower(col) LIKE lower(:kw)`；不依赖 PG `ILIKE` |
| 排序规则 | 中文排序不依赖数据库 collation；展示层排序按业务字段 |

### 2.3 公共字段词典

| 字段名 | 物理类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint` | 否 | 自增 | 主键 |
| `status` | `varchar(16)` | 否 | 视表而定 | 通用启停/业务状态（见 2.4） |
| `remark` | `varchar(512)` | 是 | `NULL` | 备注 |
| `created_by` | `bigint` | 是 | `NULL` | 创建人（系统生成行为可空） |
| `created_at` | `datetime(3)` | 否 | `CURRENT_TIMESTAMP(3)` | 创建时间 |
| `updated_by` | `bigint` | 是 | `NULL` | 更新人 |
| `updated_at` | `datetime(3)` | 否 | `CURRENT_TIMESTAMP(3)` | 更新时间 |
| `version` | `int` | 否 | `0` | 乐观锁版本号（快照/日志类表不适用） |

### 2.4 公共枚举词典

| 枚举名 | 取值 | 含义 | 适用表/字段 |
| --- | --- | --- | --- |
| `entity_status` | `enabled` / `disabled` | 主档启停状态 | `sys_user.status` |
| `quote_quality_status` | `confirmed` / `auto_extracted` / `needs_review` / `no_valid_price` / `deleted` | 数据质量状态（docs/03 5.2） | `quote.status` |
| `batch_status` | `pending` / `confirmed` / `failed` / `partial` | 导入批次状态（docs/03 5.2） | `import_batch.status` |
| `row_result_status` | `ok` / `warn` / `error` / `duplicate` | 行级导入结果（docs/03 5.2） | `import_row_result.status` |
| `user_role` | `user` / `maintainer` / `admin` | 用户角色（docs/03 5.1） | `sys_user.role` |
| `audit_action` | 见 docs/03 R-SYS-01 字典 | 审计动作 | `audit_log.action` |

### 2.5 约束承接规则

| 约束类型 | 承接层 | 说明 |
| --- | --- | --- |
| 主键、非空、普通唯一约束 | 数据库强约束 | 必须由数据库兜底 |
| 同构引用关系 | 优先数据库外键 | quote→material/supplier/source_row_snapshot 等稳定引用建外键 |
| 异构作用域引用 | 应用事务约束 | audit_log.object 多态引用不建物理外键 |
| 跨行状态切换 | 应用事务约束 | 批次提交、修订链路由事务保证 |
| 快照不可变 | 应用层禁止更新 + 数据库触发器（PG 生产） | source_row_snapshot / source_file 原值不允许 UPDATE（R-IMP-26） |

### 2.6 命名与索引规则

- 表名：`<domain>_<entity>` 复数统一用单数名词（如 `sys_user`、`quote`、`import_batch`）
- 唯一索引命名：`uk_<table>_<field...>`
- 普通索引命名：`idx_<table>_<field...>`
- 外键命名：`fk_<table>_<field>`
- 历史表和日志表（quote_revision、audit_log）默认 append-only，不提供业务更新接口

## 4. 数据表详细设计

### 4.1 [MOD-01] 认证与用户

> 承接 F-001~F-004。会话撤销语义见 docs/02 ADR-004。

#### 4.1.1 用户表（sys_user）

- 表用途：账号、角色与启停状态；不公开注册，仅 admin 维护
- 字段设计：

| 字段名 | 物理类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint` | 否 | 自增 | 主键 |
| `username` | `varchar(32)` | 否 | 无 | 账号，4-32 位字母数字下划线 |
| `password_hash` | `varchar(256)` | 否 | 无 | PBKDF2-SHA256(600k 迭代)+随机盐，格式 `pbkdf2_sha256$iterations$salt$hash`（R-AUTH-01） |
| `display_name` | `varchar(64)` | 否 | 无 | 姓名 |
| `role` | `varchar(16)` | 否 | `user` | `user`/`maintainer`/`admin` |
| `status` | `varchar(16)` | 否 | `enabled` | `enabled`/`disabled`（R-AUTH-06） |
| `last_login_at` | `datetime(3)` | 是 | `NULL` | 最近登录时间 |
| `created_by` | `bigint` | 是 | `NULL` | 创建人（首个 admin 为系统种子） |
| `created_at` | `datetime(3)` | 否 | 当前时间 | 创建时间 |
| `updated_by` | `bigint` | 是 | `NULL` | 更新人 |
| `updated_at` | `datetime(3)` | 否 | 当前时间 | 更新时间 |
| `version` | `int` | 否 | `0` | 乐观锁 |
| `remark` | `varchar(512)` | 是 | `NULL` | 备注 |

- 索引与约束：
  - `uk_sys_user_username`：`username` 唯一
- 补充规则：
  - 停用不物理删除；密码永不回显；首条 admin 由启动种子脚本创建（无默认密码，首启生成随机密码输出到日志并要求修改）

#### 4.1.2 会话表（sys_session）

- 表用途：JWT 会话撤销登记；退出/停用/重置密码时删除或标记撤销，实现即时失效（FR01/FR04）
- 字段设计：

| 字段名 | 物理类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint` | 否 | 自增 | 主键 |
| `user_id` | `bigint` | 否 | 无 | 引用 sys_user.id |
| `jti` | `varchar(64)` | 否 | 无 | JWT 唯一标识 |
| `created_at` | `datetime(3)` | 否 | 当前时间 | 创建时间 |
| `expires_at` | `datetime(3)` | 否 | 无 | 过期时间（默认创建+12h，可配置） |
| `revoked_at` | `datetime(3)` | 是 | `NULL` | 撤销时间（退出/停用/重置） |
| `ip` | `varchar(64)` | 是 | `NULL` | 登录 IP |
| `user_agent` | `varchar(256)` | 是 | `NULL` | 登录 UA 摘要 |

- 索引与约束：
  - `uk_sys_session_jti`：`jti` 唯一（每请求校验点）
  - `idx_sys_session_user_id`：`user_id`（停用批量撤销）
  - `idx_sys_session_expires_at`：`expires_at`（过期清理任务）
- 补充规则：
  - 会话校验语义：`jti 存在 AND revoked_at IS NULL AND expires_at > now() AND user.status='enabled'`
  - 过期会话由每日任务清理；本表可删除，不计审计

### 4.2 [MOD-02] 核心业务对象与查询

> 承接 F-012/F-013/F-014~F-019。关系：material 1..N purchase_requirement 1..N quote；supplier 1..N quote；quote → source_row_snapshot 不可空（可追溯率 100%，ADR-003）。

#### 4.2.1 物料表（material）

- 表用途：被采购的商品/设备标准信息（PRD 7.2 物料组）
- 字段设计：

| 字段名 | 物理类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint` | 否 | 自增 | 主键 |
| `code` | `varchar(64)` | 是 | `NULL` | 物料编码 |
| `name` | `varchar(128)` | 是 | `NULL` | 物料名称 |
| `category` | `varchar(64)` | 是 | `NULL` | 分类（管道串拆分所得，原文另存快照） |
| `spec_model` | `varchar(256)` | 是 | `NULL` | 规格型号 |
| `tech_params` | `text` | 是 | `NULL` | 技术参数 |
| `part_no` | `varchar(128)` | 是 | `NULL` | 零件号/图号 |
| `material_text` | `varchar(128)` | 是 | `NULL` | 材质 |
| `brand` | `varchar(64)` | 是 | `NULL` | 品牌 |
| `origin_type` | `varchar(16)` | 是 | `NULL` | 进口/国产 |
| `unit` | `varchar(32)` | 是 | `NULL` | 单位 |
| `name_raw` | `text` | 是 | `NULL` | 物料描述原文（管道串整串保留，R-IMP-13） |

- 索引与约束：
  - `idx_material_name`、`idx_material_code`、`idx_material_spec_model`、`idx_material_brand`（搜索域，R-QRY-01）

- 补充规则：
  - 导入按去重键归并复用既有物料；不随批次物理删除

#### 4.2.4 原始行快照表（source_row_snapshot）

- 表用途：源 Excel 行的单元格级原文与定位，可追溯率 100% 的事实源；不可变（R-IMP-26）
- 字段设计：

| 字段名 | 物理类型 | 空值 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `bigint` | 否 | 自增 | 主键 |
| `source_file_id` | `bigint` | 否 | 无 | 引用 source_file.id（MOD-03） |
| `sheet_name` | `varchar(128)` | 否 | 无 | 工作表名 |
| `row_no` | `int` | 否 | 无 | 源行号（1 基） |
| `cells` | `json` | 否 | 无 | 列名→值 的整行原文（含未映射列） |
| `content_hash` | `varchar(64)` | 否 | 无 | 整行内容 SHA-256（行级重复判定，R-IMP-19） |
| `created_by` | `bigint` | 是 | `NULL` | 上传人 |
| `created_at` | `datetime(3)` | 否 | 当前时间 | 上传时间 |

- 索引与约束：
  - `uk_snapshot_row_identity`：`(source_file_id, sheet_name, row_no)` 唯一
  - `idx_snapshot_content_hash`：`content_hash`
  - `fk_source_row_snapshot_file` 外键
- 补充规则：
  - append-only：禁止 UPDATE/DELETE（PG 生产用触发器兜底；应用层不提供更新）
  - `version` 字段不适用

### 4.3 [MOD-03] Excel 导入
