# POM API 和数据库任务清单

> 驱动 docs/05-API接口设计.md 与 docs/06-数据库设计.md 的逐模块补文。每条任务只处理当前模块，同步更新两侧文档。

## 1. 模块依赖图

```text
MOD-01 认证与用户（基础能力）
   └──→ MOD-02 核心业务对象与查询（物料/需求/供应商/快照/报价）
            └──→ MOD-03 Excel 导入（批次/文件/行级结果/映射模板，写入 MOD-02 对象）
                     └──→ MOD-04 数据维护与修订（修订链）
                              └──→ MOD-05 系统管理与审计（横切，依赖全部事件源）
```

## 2. 波次建议

| 波次 | 任务 | 依赖 | 理由 |
| --- | --- | --- | --- |
| W1 | API-DB-001 | 无 | 登录/会话是所有接口的前置 |
| W2 | API-DB-002 | API-DB-001 | 核心对象与查询是导入的写入目标 |
| W3 | API-DB-003 | API-DB-002 | 导入引擎落库依赖核心表 |
| W4 | API-DB-004 | API-DB-003 | 纠错依赖已入库数据 |
| W5 | API-DB-005 | API-DB-004 | 审计横切最后收口 |

## 4. 任务卡片

### API-DB-001 认证与用户

- 目标章节: API docs/05 4.1；DB docs/06 4.1
- 覆盖功能: F-001~F-004（登录/退出/超时、用户启停重置、角色、限速）
- 必读输入: docs/03 4.1；docs/04 分册A/E1；docs/02 ADR-004
- 完成定义: MOD-01 全部接口按 1.4 固定结构补齐（含错误码）；sys_user/sys_session 字段、索引、约束补齐；任务状态回写 DONE
- 一致性检查: 会话撤销语义与 ADR-004 一致；角色枚举与 docs/03 5.1/5.2 一致
- 状态: DONE（2026-09-09 完成，含 7 接口卡片 + 2 表）

### API-DB-002 核心业务对象与查询

- 目标章节: API docs/05 4.2；DB docs/06 4.2
- 覆盖功能: F-012/F-013/F-014~F-019（快照、结构化库、搜索/筛选/排序/详情/历史/空态、文件下载）
- 必读输入: docs/03 4.2/4.3；docs/04 分册B；docs/02 ADR-003
- 完成定义: 5 接口卡片补齐；material/purchase_requirement/supplier/source_row_snapshot/quote 五表字段、索引、约束补齐；可追溯率 100% 的非空约束落定
- 一致性检查: quote→snapshot 不可空；状态字典一致；敏感字段脱敏在 API 层而非 DB 层
- 状态: DONE（2026-09-09 完成，含 5 接口卡片 + 5 表）

### API-DB-003 Excel 导入

- 目标章节: API docs/05 4.3；DB docs/06 4.3
- 覆盖功能: F-005~F-011（上传/识别/映射/预览/拆分/去重/报告）
- 必读输入: docs/03 4.2；docs/04 分册C；样例结构观察（fixtures）
- 完成定义: 9 接口卡片补齐；import_batch/source_file/import_row_result/mapping_template 四表补齐；批次事务与幂等（commit_token）落定
- 一致性检查: 行级结果状态字典与 docs/03 5.2 一致；文件哈希唯一策略与 R-IMP-18 一致
- 状态: DONE（2026-09-09 完成，含 9 接口卡片 + 4 表）

### API-DB-004 数据维护与修订

- 目标章节: API docs/05 4.4；DB docs/06 4.4
- 覆盖功能: F-020~F-022（纠错留痕/软删除恢复/异常标记）
- 必读输入: docs/03 4.4；docs/04 分册D
- 完成定义: 5 接口卡片补齐；quote_revision 表补齐；乐观锁与 append-only 约束落定
- 一致性检查: 修订记录字段覆盖 R-MNT-02；快照不可变不因修订破坏
- 状态: DONE（2026-09-09 完成，含 5 接口卡片 + 1 表）

### API-DB-005 系统管理与审计

- 目标章节: API docs/05 4.5；DB docs/06 4.5
- 覆盖功能: F-023~F-025（审计/备份状态/敏感字段控制）
- 必读输入: docs/03 4.5；docs/04 分册E；docs/02 8.5
- 完成定义: 2 接口卡片补齐；audit_log 表补齐；审计动作字典落定
- 一致性检查: 审计动作枚举与 R-SYS-01 一致；多态对象引用不建物理外键
- 状态: DONE（2026-09-09 完成，含 2 接口卡片 + 1 表）
